# 🏓 Neon Pong

A modern, arcade-style **Pong game** with a futuristic neon arena, glowing effects, dynamic ball movement, collision particles, and screen-shake feedback.

Built to give the classic Pong experience a more energetic and modern feel. ⚡

## ✨ Features

* 🌌 **Animated Neon Arena** — Futuristic visual style with an animated game environment.
* ✨ **Ball Glow & Motion Trail** — The ball leaves a dynamic trail as it moves.
* 💥 **Collision Particles** — Visual particle effects appear when the ball interacts with paddles.
* 📳 **Screen Shake** — Collisions and scoring events provide additional impact through screen-shake effects.
* ⚡ **Progressive Ball Speed** — The ball gradually becomes faster, increasing the challenge as the game continues.
* 🏆 **Score System** — Keeps track of both players' scores.
* 🎮 **Classic Pong Gameplay** — Simple controls with increasingly challenging gameplay.
* 📱 **Responsive Design** — Designed to work across different screen sizes.
* 🎨 **Modern UI** — Neon-inspired arcade visuals instead of the traditional plain Pong appearance.

## 🎮 How to Play

The objective is simple:

> Get the ball past your opponent's paddle while keeping it from reaching your own side.

### Controls

| Action    | Player 1 |
| --------- | -------- |
| Move Up   | `W`      |
| Move Down | `S`      |

## 🕹️ Gameplay

The game starts with the ball moving across the arena.

As the game progresses:

1. 🏓 Players move their paddles to intercept the ball.
2. 💥 Paddle collisions trigger visual feedback.
3. ⚡ The ball gradually increases in speed.
4. 🏆 Missing the ball gives the opponent a point.
5. 🔥 The increasing speed makes longer rallies progressively more difficult.

## 🎨 Visual Effects

The game focuses heavily on arcade-style feedback.

### Neon Arena

A futuristic animated arena provides the game's main visual environment.

### Ball Trail

The ball uses a glowing trail to make its movement easier to follow and more visually dynamic.

### Collision Particles

Paddle collisions generate particles to make impacts feel more responsive.

### Screen Shake

Important gameplay events use subtle screen shake to add impact and feedback.
